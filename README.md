# TextMeld 浏览器版 · v1.4.1

在浏览器里识别图片中的字、修补旧字位置并绘制新字。适合部署到 GitHub Pages。识别和修补运行在访问者的设备上，草稿和字体保存在浏览器。

## 使用

1. 第一次打开时点击「下载识别资源」。模型和运行库合计约 53 MiB，下载完成后可复用。
2. 选择图片，框选或涂抹一处文字。点「扫描并推荐字体」可查看根据原字形排序的近似字体。
3. 点「下载并预览」取用某个候选。也可直接用系统字体，或在「字体匹配」中搜索开放字库、上传 TTF 或 OTF。
4. 填入新文案并点击「应用这一处」。可以查看原图与结果、继续改下一处，或下载合成的 PNG。

等字数的中文默认按原字位排版，并可微调字距。字位计算尽量沿用原笔画的中心位置，保留选区附近未涂到的标点。旧草稿可重新应用该处改动。

模型与页面是在同一个静态网站内分开的资源。用户点击确认后才请求模型。字体从已登记的开放字体来源按需下载，下载后存在本浏览器。

## 构建和部署

访问已经发布的站点只需要浏览器。自己重新构建时使用 Node.js 22.12 或更高版本和 npm。

```sh
npm ci
npm run build
```

把 `dist/` 中的内容整体发布。站点的入口为 `index.html`，适配 GitHub Pages 的仓库子路径。本地可用 `npx vite preview` 验证。模型缓存和离线功能需要在 HTTPS 或 localhost 下运行。

## 范围和限制

- 浏览器版沿用 PP-OCRv6 模型，文字检测后处理、图像修补与字体绘制由浏览器完成。实际效果会因图片、系统字体和设备而异。
- 建议对单行或单列文字做较紧的选区。复杂纹理、遮挡和极限角度可能有残留。系统字体按设备提供的字形渲染，下载或上传字体可获得更一致的字形。
- 字形索引用于开放字体的近似排序，覆盖常见汉字和拉丁字符。匹配质量取决于选区和候选覆盖。目录可搜索 1,884 个家族。
- 云端识别、云端擦除与凭据配置属于 v1.3.5 的后端版。此版本独立运行，草稿和已添加的字体按浏览器与站点地址保存。
